**Blocker**

- `docs/zhl/migrations/025_zhl_rueckgabe.sql` enthält einen produktionswirksamen Testseed für `resource_id = 22`.
- Code und Adminpfad hängen hart an der neuen Spalte `zhl_uebergabe.rueckgabe`; Migration muss vor Deploy laufen und committed sein.

**Vor Deploy fixen**

- `lookupUebergabe()` muss `rueckgabeort` zurückgeben, sonst fehlt der Rückgabeort im Buchungsformular.
- Pool-Zuteilung gegen abweichende ZHL-Konfigurationen absichern, sonst kann ein Return-Slot vom ursprünglichen Gerät an der automatisch zugewiesenen Einheit hängen.
- Backfill-Fehlschläge für Handover-Referenzen nicht nur loggen; sonst werden gebuchte Return-Slots später von Detail/Storno nicht gefunden.
